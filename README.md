# Prompt Library

Thư viện prompt cá nhân chạy hoàn toàn trên trình duyệt, không cần cài đặt hay backend.

## Dùng thử

Mở `index.html` trong trình duyệt. Nếu muốn dùng clipboard ổn định trên thiết bị di động, hãy chạy qua HTTPS hoặc localhost.

- Tìm kiếm prompt bằng ô tìm kiếm hoặc nhấn `/`.
- Lọc theo danh mục.
- Copy ngay từ thẻ hoặc mở trình sửa để thay đổi nội dung rồi copy.
- Prompt mới và các chỉnh sửa được lưu trong `localStorage` của trình duyệt hiện tại.

Prompt mẫu được đóng gói cùng ứng dụng. Dữ liệu do bạn tạo hoặc chỉnh sửa không được gửi lên máy chủ và không tự đồng bộ giữa các trình duyệt.

## Phát triển

Đây là website tĩnh thuần HTML, CSS và JavaScript; không cần bước build hay dependency.
