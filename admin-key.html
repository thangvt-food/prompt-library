p. promptlibrary

CÔNG CỤ OFFLINE

Tạo mã quản trị mới.

Tạo một mã ngẫu nhiên 256-bit bằng bộ sinh số an toàn của trình duyệt, rồi băm SHA-256 thành chuỗi 64 ký tự hex để dùng làm mật khẩu quản trị.

ⓘ Trang này không kết nối Cloudflare và không gửi dữ liệu đi đâu. Chỉ tạo mã ngay trên thiết bị của bạn. Mã quản trị không hết hạn; chỉ phiên đăng nhập mới hết hạn sau 7 ngày.

Chuỗi này là mật khẩu đăng nhập và cũng là giá trị mới cho Cloudflare Secret ADMIN_PASSWORD.

Đẩy mã mới lên Cloudflare

Dán API token có quyền Workers Scripts:Write để cập nhật Secret ADMIN_PASSWORD cho Worker prompt-library-api. Tạo API token

Để tránh gửi token qua một website public, hãy chạy npm run admin:key trong thư mục dự án rồi mở địa chỉ local mà lệnh in ra. Nút đẩy chỉ hoạt động trên máy của bạn.

Cập nhật trong Cloudflare Dashboard

  1. Đăng nhập Cloudflare Dashboard → Workers & Pages → prompt-library-api.
  2. Mở Settings → Variables and Secrets; sửa hoặc thêm Secret ADMIN_PASSWORD.
  3. Sao chép mã mới ở trên vào giá trị Secret, rồi lưu/deploy Worker.
  4. Đăng nhập lại tại Prompt Library bằng chính mã vừa tạo.

Mã mới có hiệu lực ngay khi Worker được deploy và sẽ làm các phiên quản trị cũ mất hiệu lực. Nếu chọn “Tải file lưu riêng”, hãy giữ file ở nơi riêng tư; bất kỳ ai có mã này đều có thể sửa thư viện.
